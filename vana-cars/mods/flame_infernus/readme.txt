Flame Infernus v4.0

Original model and textures by: Silver3o5
Slightly edited model and new textures by: FunGt


ISTRUCTIONS - HOW TO ADD CUSTOM STRIPES:
1. Download TXD Workshop from here:
http://www.gta-modding.com/area/index.php?act=view&id=4
2. Drag and drop infernus.txd into the program.
3. Select the "map" image, the third one.
4. Click Import and select one of the PNG files contained into Stripes folder of this mod.
5. Click Save TXD and close the program.
6. Run Alci's IMG Editor or any other IMG program and import DFF and TXD into gta3.img located in models folder.


You can edit this Infernus as you want and I'd appreciate if you make some new skins.


INFORMATIONS:
DFF Primary Color: stripes changes as primary color.
DFF Secondary Color: stripes changes as secondary color.
Always black: there are no stripes, the car is always black, any color you choose.
