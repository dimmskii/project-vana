[RU]
Быстрый вариант установки пака, если не хотите возиться с установкой и не можете понять что и как устанавливать.
Не рекомендуется для тех, у кого сборка напичкана кучей модов или же моды занимают множество ID, так как может появиться множество конфликтов  файлов.

Если же у вас полностью чистая игра, то сначала установите Essentials Pack и MixSets, и после этого извлеките все файлы из папки EVVPR 2.0. в папку игры и подтвердите замену.

После установки выставьте в Mix Sets:
NoPaintjobToWhite    = 1  
NoFixHandsToBars     = 1
TuningChoose2colors  = 1 




[EN]
A quick installing of the pack, if you don't want to mess with the installation and can't figure out what to install and how.
It is not recommended for those whose game has lots of mods or mods use a lot of IDs, as there may be a lot of file conflicts.

If you have a clean game, first install the Essentials Pack and MixSets, and then extract all the files from the EVVPR 2.0 folder to the game folder and confirm the replacement.

After installation sets in Mix Sets:
NoPaintjobToWhite    = 1  
NoFixHandsToBars     = 1
TuningChoose2colors  = 1
